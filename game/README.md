# game/ —— Godot 4 工程

玩法写在这里（GDScript + 场景 + 资源）。

## 现在有什么

**第一版 3D 牌桌原型。** 刻意很丑：桌子是方块、人是胶囊、牌是薄片 + 3D 文字。
这一版要验证的不是画面，是**牌桌循环能不能转起来**。

四个座位围着桌子，你是座位 0：
点一张手牌 → 结算 → 记忆值变化 → 轮到对手 → 一轮结束全体记忆 −1 → 直到分出胜负。

| 文件 | 作用 |
|---|---|
| `rules.gd` | **纯规则**，不引用任何节点，可无头跑、可单测 |
| `ai.gd` | 对手逻辑，够活就行，以后只改这一个文件 |
| `main.gd` | 3D 场景搭建 + 交互 + 回合驱动 |
| `main.tscn` | 只有一行：Node3D + main.gd |

## 跑

```bash
godot --path game                      # 打开玩
godot --headless --path game -- --auto # 无头自对局，验证规则没坏
```

`--auto` 会打印一局结果然后退出，退出码 0 表示分出胜负了。

## 这一版故意没做

按重要性排：

1. **目标选择** —— 现在的目标座位是自动挑的（杀伤打记忆最高的人）。真要做成
   "点牌 → 点人"的两段式。
2. **枪和抢枪** —— 开局那个环节整块还没进来。
3. **身份线索的呈现** —— 现在只有"记忆值到了 7/9 解锁"的文字提示，
   还没有"侦探笔记"这种能看见推演过程的东西。
4. **剧情、美术、音效** —— 全没有。

## 规则数值来自哪里

`docs/design-validation.md`。牌池权重、记忆值经济、解锁阈值都在那里验证过。
改数值请两边一起改，别让 Godot 里的实现和文档对不上。
