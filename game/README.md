# game/ —— Godot 4 工程

**3D 牌桌 demo。** 刻意很丑：桌子是方块、人是胶囊、牌是薄片 + 3D 文字。
要验的不是画面，是"这个循环好不好玩"。

## 场景是代码生成的

`main.tscn` 里只有一个空 `Node3D` + `main.gd`。桌子、四个座位、灯光、那把枪
全部在 `_ready()` 里用代码建出来，挂在运行时创建的 `GEN` 节点下面。

这样做的好处是改布局不用手点编辑器；代价是**编辑器里打开看不到东西**。
所以脚本加了 `@tool`：现在编辑器里能看到静态部分（桌子、四个座位、枪），
对局相关的（手牌、状态文字、抢枪按钮）仍然只在运行时出现。

注意 `GEN` 下的节点是生成物，不会被存进 `.tscn`。想真正"拖一下桌子"这种
可视化编辑，得把这些节点改成场景里真实存在的节点，脚本只填动态部分——
这一步还没做。

## 一局是什么样

1. **抢枪** —— 桌上有枪。四人同时选「抢 / 躲 / 盯」。
   抢的人里随机一个拿到枪；躲的人记忆 +1；盯的人能看到持枪者一张手牌。
2. **出牌** —— 从持枪人起顺时针，每人打一张牌。也可以跳过。
3. **轮末** —— 所有人记忆 −1（失忆会退）。记忆到 0 出局。
4. **解锁** —— 记忆到 7 你隐约知道自己是好是坏，到 9 你知道自己是谁。
5. **开枪** —— 持枪人从第 2 轮起可以开枪（一局一发）：目标直接出局，
   他的记忆涌进你脑子里（+3）。所以开枪是变强，也是暴露。

分出胜负：卧底出局 → 好人胜；卧底活到第 8 轮或场上只剩 2 人 → 卧底胜。

## 操作

| 阶段 | 操作 |
|---|---|
| 抢枪 | 点屏幕中间的三个按钮 |
| 出牌 | 点一张手牌；需要目标时座位会**变红**，再点那个人 |
| 取消选择 | 再点任意一张牌 |
| 开枪 | 持枪且第 2 轮起，右下角「开枪」，再点人 |

## 跑

```bash
godot --path game                       # 打开玩
godot --headless --path game -- --auto  # 无头自对局，验证规则没坏
```

`--auto` 打印一局结果后退出，退出码 0 表示分出胜负了。

## 文件

| 文件 | 作用 |
|---|---|
| `rules.gd` | **纯规则**，不引用任何节点，可无头跑、可单测。抢枪/出牌/开枪/胜负都在这 |
| `ai.gd` | 对手逻辑，够活就行，以后只改这一个文件 |
| `main.gd` | 3D 场景搭建 + 点击 + 回合驱动 |
| `main.tscn` | 一行：Node3D + main.gd |

## 还没做（按优先级）

1. **身份线索的呈现** —— 现在只有一行"记忆到 7/9 解锁"的文字。这是这个游戏的核心体验，
   应该有"侦探笔记"之类能看见推演过程的东西。
2. **角色的辨识度** —— 四个胶囊长得一样，记不住谁是谁。
3. **剧情、美术、音效** —— 全没有。
4. 打包成可执行文件（需要先装 Godot 导出模板）。
